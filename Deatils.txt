📌 Brief Explanation of the Student Grading System Project
This project is a Student Grading System that allows users to enter student details (Name and Marks) via a modern web interface, stores them in local storage, exports them to a CSV file, and processes them using a C++ backend.

🛠️ Technology Stack
Component	Technology Used
Frontend (UI)	HTML, Tailwind CSS, JavaScript
Data Storage	LocalStorage (Browser-based)
Export Data	CSV File Format
Backend (Processing)	C++ (Handles CSV Reading & Grade Calculation)
🚀 Features
✅ Modern UI with Tailwind CSS - Clean, professional design.
✅ Dynamic Data Storage (LocalStorage) - Even after refreshing, data persists.
✅ CSV Export Feature - Allows students' data to be saved in a file.
✅ C++ Backend Processing - Reads the CSV file, calculates grades, and displays the results.

🖥️ How It Works?
📌 1. Frontend (index.html)
Student enters details (Name & Marks).
Marks are automatically converted into a Grade.
Data is stored in LocalStorage for persistence.
Data is displayed in a table dynamically.
Export CSV button generates a students.csv file.
📌 2. CSV File (students.csv)
This file is generated when users export the data.
It follows this format:

📌 3. Backend (C++ Program)
The C++ program reads the students.csv file.
It extracts the student details (ID, Name, Marks).
The Grade is calculated if not present.
The formatted student records are displayed in the terminal.
